# Бесконечные Острова

Браузерный игровой прототип по ТЗ версии 3.0. Запускается как статическая игра для Яндекс Игр и локально через Vite. Исходный код написан на TypeScript, сцена и персонажи собраны из настоящей 3D-геометрии Three.js, столкновения героя с островом и объектами обрабатывает Rapier.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

    npm ci
    npm run dev

Откройте адрес, который напечатает Vite. Проверки и сборка:

    npm test
    npm run build
    npm run preview

В каталоге dist находятся файлы для загрузки на игровую платформу. При упаковке в ZIP корнем архива должен быть **контент каталога dist**, чтобы index.html лежал в корне архива. Серверная часть Vite нужна только для локальной разработки; опубликованная игра работает в браузере и хранит контрольные точки локально и, при доступности SDK, в данных игрока Яндекс Игр.

## Игровой цикл

Выберите одного из четырёх героев в лобби. На каждом острове появляется одна группа противников. После её уничтожения войдите в портал и выберите награду. Забег заканчивается после 20-го острова. Сохранение делается в начале каждого острова; при перезагрузке бой на текущем острове начинается заново.

- WASD или стрелки — движение; мышь — прицеливание; ЛКМ — огонь.
- Q или ПКМ — активная способность; Space — рывок; R — перезарядка.
- 1 / 2 или колесо — оружие; C — характеристики; Tab — инвентарь; Esc — пауза; F3 — инструменты разработчика.
- На сенсорном экране доступны джойстик, огонь, способность и рывок.

## Интеграция Яндекс Игр

Адаптер в src/sdk.ts загружает https://yandex.ru/games/sdk/v2. После подготовки сцены вызывается LoadingAPI.ready(). GameplayAPI.start() и stop() следуют за игровым состоянием и паузой. Полноэкранная реклама запрашивается только при переходе между каждыми пятью островами. За просмотр рекламы с подтверждённым onRewarded один раз за забег можно воскреснуть. Во время рекламы игровой процесс и звук ставятся на паузу. Вне платформы SDK и реклама необязательны, игра остаётся доступной.

Для проверки рекламных показов и облачного сохранения нужен запуск внутри тестового окружения Яндекс Игр. Локальная сборка не доказывает, что рекламная сеть покажет объявление.

## Статус относительно полного ТЗ

Работают меню, лобби, 4 героя, 4 биома, бой, добыча, разрушаемые ящики/бочки/фонтан, 20-островный цикл, портал, награды, 7 босс-столкновений с тремя фазами, 30 конфигураций оружия, сохранение и финал. Каталоги содержат 40 обычных и 20 элитных врагов, 15 активных и 20 пассивных способностей.

Это **не полная версия по всем пунктам ТЗ**. Геометрия пока процедурная: 40 названных форм используют 8 семейств контура; виды врагов разделяют наборы поведения; модели не имеют исходников Blender, скелетов, отдельных GLB, художественных анимаций и звуков. Не реализованы 7 NPC, все уникальные механики оружия/способностей, полноценные RPG-сервисы и Node.js сервер для истории забегов. Эти элементы требуют отдельного производства ассетов, дизайна и балансировки.

Страница [критериев Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/criteria) должна быть проверена перед публикацией. Из текущей облачной среды она ответила CONNECT tunnel failed, response 403, поэтому утверждать соответствие всем критериям нельзя. В репозитории проверены сборка, тесты данных и игровой сценарий в Chromium; интеграция SDK требует проверки на самой платформе.
